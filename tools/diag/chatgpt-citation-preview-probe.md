# ChatGPT 引用来源标签与悬停卡片探针

针对这次截图：原始视图悬停 `DeepSeek API …` 会出现来源卡片，专注会话只显示小标签。
本探针测量入口的真实结构、外层包装、悬停与点击后的卡片、卡片中的来源链接及图片承载方式，
并报告当前引用适配器的公开选择器和筛选条件是否覆盖该入口。采集结果用于下一步修复。

它是自包含的只读观察器，不导入项目模块，不加载终端提示词注入器，不自动悬停、点击、输入或发消息。
**由用户运行和操作，智能体只读日志。**

先完整退出 Web2Term，包括托盘中的实例，避免同时占用真实会话分区。在 PowerShell 中执行：

```powershell
& 'C:\codes\gpt-web-to-codex-terminal\node_modules\electron\dist\electron.exe' 'C:\codes\gpt-web-to-codex-terminal\tools\diag\chatgpt-citation-preview-probe.cjs'
```

默认打开本次截图的 ChatGPT 会话。无需再生成回答，也无需操作专注视图。

1. 找到红框里的 **DeepSeek API 来源标签**，将鼠标悬停两秒。
2. 来源卡片出现后，保持鼠标在标签上，按 **F8**。不要为了采集去点击菜单，以免悬停卡片关闭。
3. 将鼠标移到卡片内部停留两秒，再按 **F8**，以记录卡片与来源链接之间的结构关系。
4. 将鼠标移到空白处，等卡片消失，再手动点击同一来源标签一次。如果出现卡片或来源列表，保持打开并按 **F8**。
5. 可手动点击卡片中的一个来源链接；正常打开的外部网页不注入读取器。若页面跳转，可手动返回。
6. 关闭探针主窗口，将终端打印的 **“日志已保存：……”路径**发回来。

如果某一步没有弹层，停在当时状态按 F8 后继续，最后说明“悬停是否出现卡片、点击后是什么表现”。
标题会显示入口、弹层、链接各自是否已经采集。这里只报告覆盖，未采集不能直接判定功能不存在。

日志写入 `%TEMP%\gpt-login-diag\chatgpt-citation-preview-<时间>-<进程号>.log`，使用 `fs.appendFileSync`。
每次运行最多约 8 MB，达到上限会在 `FINAL.capped` 中标记。

| 日志 | 用途 |
| --- | --- |
| `SNAPSHOT.candidates` | 小型来源入口、原生点击处理是否存在、ARIA/data 属性、父级结构、尺寸与裁切样式 |
| `candidates[].adapter` | 当前引用选择器是否匹配、是否有显式引用标记、HTTP 链接数量及现有筛选条件的覆盖 |
| `USER-INTERACTION` | 用户真实的悬停、离开、聚焦、入口点击和卡片内点击；包含当时入口与父级结构 |
| `SNAPSHOT.popups` | ARIA 关联或新出现的弹层结构，是否符合现有弹层选择器、来源链接、图片/SVG/iframe 等承载方式 |
| `CLICK-FINISHED` | 原网页是否阻止点击默认行为 |
| `NAVIGATION` / `NEW-WINDOW-REQUEST` | 用户操作导致的来源导航，地址仅保留脱敏结构 |
| `FINAL.coverage` | 入口、悬停、点击、弹层、弹层内链接和来源导航的覆盖情况 |

隐私范围：不记录会话正文、输入内容、Cookie、令牌、存储、请求或响应体、React 私有对象、截图、HTML 源文。
标签、标题、动态属性和标识符仅记录长度、类别及本次运行内的引用；URL 省略参数值、片段、凭据和动态路径段，
仅保留协议、来源类别、固定路径形状和引用。DOM 树只包含元素结构及受限属性，不复制文本节点。
不注册 `webRequest` 监听器，不主动请求来源，不修改页面内容或阻止用户原生点击。

可选环境变量：`PROBE_START_URL`（仅允许 ChatGPT 同源）、`PROBE_SOURCE_MESSAGE_ID`（仅查看某条回复）、
`PROBE_USER_DATA`（已有用户目录）、`PROBE_PROXY`（默认 `http://127.0.0.1:7897`）。复用原目录及 `persist:chatgpt`。

智能体只做语法检查和构建，不运行探针。**构建通过，等待用户运行采集。**
