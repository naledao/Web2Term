# DeepSeek 创建分享链接与后台获取

本探针验证用户当前需要的步骤：在“询问 AI”输入问题后按 Enter，后台得到分享链接，
不打开 DeepSeek 分享弹窗。它不新建聊天，也不把问题发给模型。

需要先人工完成一次网站原生分享流程，采集真实创建请求。
用户日志已确认 `POST /api/v0/share/create` 成功时返回
`data.biz_data.share_id`；现在直接从这个字段得到分享链接，不依赖剪贴板。
探针不猜内部接口，不自动点击分享，也不撤销或删除旧分享。
智能体只写探针、读日志，用户运行和操作。

先关闭正常应用，再从仓库根目录运行：

```powershell
.\node_modules\electron\dist\electron.exe .\tools\diag\deepseek-share-create-probe.cjs
```

复用当前应用的 `persist:deepseek` 登录分区，本次进程内代理默认
`http://127.0.0.1:7897`。可用 `PROBE_PROXY`、`PROBE_USER_DATA` 覆盖。
`PROBE_START_URL` 可指定当前 DeepSeek 会话地址；默认首页。

1. 在探针中打开要测试的原会话。
2. 按 **F6** 开始采集最后一条回答；也可以按 **Shift+F6** 标记“较早回答”这一组。
3. **手动**点击对应回答的分享按钮，按网站流程创建链接。
   **不需要点复制，也不需要 F7**；探针收到成功响应后自动取出链接。
4. 出现 `CREATED-LINK`、`TEMPLATE-LEARNED` 后，**关闭网站的分享弹窗**。
5. 在刚才分享的**同一条回答**中选中文字，点“询问 AI”输入框，输入问题并按 **Enter**。
   也可按 **F9**，单独检查后台 HTTP 请求。
6. 后台只重放刚才捕获并已关联链接的创建请求，成功时自动把返回的链接复制进剪贴板。
   脚本不点击任何页面控件，也不打开分享弹窗。
7. 核对链接内容与消息范围，可以用菜单记录人工核对结果。关闭探针，把日志路径发给智能体。

如果只打开早已存在的链接，网页可能不发送创建请求；请按网站流程创建一次。
不会把读取、删除或不明请求当作创建请求，不需要反复登录或发送聊天消息。
F7 仅用于可选剪贴板核对，支持链接附带说明文字、查询参数或锚点；解析失败不阻止使用
创建响应中已取得的链接。此时只记录剪贴板长度、格式名称和是否含分享地址，不记录其他文本。

日志和操作步骤文件位于 `%TEMP%\gpt-login-diag\`：

```text
deepseek-share-create-<timestamp>-<pid>.log
deepseek-share-create-<timestamp>-<pid>.txt
```

| 事件 | 意义 |
| --- | --- |
| `BASELINE-START` | 当前人工采集组与原会话摘要 |
| `SHARE-REQUEST` | 分享相关的真实 URL 路径、方法、请求字段结构、消息编号或数组长度、请求头名称 |
| `SHARE-RESPONSE-SCHEMA` | 返回字段结构；文本及认证字段隐藏，提供可定位链接的字段路径 |
| `CREATED-LINK` | 从成功创建响应的 `share_id` 直接取得链接，不读剪贴板 |
| `COPIED-LINK` | 用户按 F7 明确读取的分享链接，不持续监听剪贴板 |
| `TEMPLATE-LEARNED` | 已通过实测的成功创建响应取得请求与返回字段，或经可选复制链接关联 |
| `TEMPLATE-NOT-LEARNED` | 无创建请求、返回不包含该链接标识，或存在歧义；不重放 |
| `QUESTION-ENTER` | 在选区输入框内回车；只记录问题和选区长度 |
| `BACKGROUND-START` / `BACKGROUND-RESPONSE` | 显式触发的后台请求与返回结构；不自动重试 |
| `BACKGROUND-LINK` | 后台返回并复制的实际链接，以及标准对话框数量前后观察值 |
| `USER-CHECK` | 人工检查“无弹窗且范围正确”或存在问题 |
| `UI` | 实际分享控件的类名、角色、标签与标准弹窗结构；可用 F8 手动采集 |

请求中的认证头仅在内存中供此次显式重放使用；Chromium 使用当前分区的 Cookie。
不把 Token、Cookie、原会话正文、问题正文、原始请求或响应写入日志；分享链接是本次
测试的明确结果，会记录。结构中的普通字符串仅记录类型和长度，ID 用摘要关联；数字
消息编号与非敏感布尔值保留，以判断分享范围参数。

每个窗口一个 CDP 网络观察器，没有重复注册 `webRequest` 监听器。只读取小型 JSON
分享相关响应。重放有 15 秒总时限、同会话约束，不自动重试。关闭时中止正在进行的后台
请求，在销毁 webContents 前做有时限的最终采集，并清理内存中的认证信息。

目前重放的是**人工分享请求的相同消息范围**，不因之后另选一段文字而擅自改写参数。
仍需日志确认如何把当前选中回答映射到分享范围。DOM 中的标准对话框计数不能发现所有
无语义标记的网页浮层，因此“没有可见弹窗”也需用户观察。
成功返回链接不代表链接中的历史范围正确，也不代表另一个模型会话能读取其中内容。
本探针不修改正式应用的 Enter 行为；正式接入应在这些测量完成后进行。
