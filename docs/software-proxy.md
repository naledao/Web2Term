# 软件代理

在 **设置 → 网络代理 → 软件代理** 中配置软件访问后端的代理。默认值为 `http://127.0.0.1:7897`，首次安装及升级后尚未保存此选项的客户端都会采用该地址。

支持 HTTP / HTTPS 代理，也可输入 `127.0.0.1:7897`，保存时补全为 HTTP 地址。清空并保存表示直连；自定义地址和明确保存的空值都会在重启后保留。不支持带账号、密码、路径、查询参数的代理地址。

## 请求范围

- 版本更新说明的列表、正文和已读登记。
- 后端验证码、登录、设备列表和设备改名。
- web2term 设备 WebSocket 连接及其后续终端通信。

网页代理、SSH 代理和更新下载代理继续使用各自已有的设置。软件代理保存后用于后续请求，更新说明会清空旧请求并重新读取；已经建立的设备连接在下次重连时采用新值。

后端 HTTP 使用独立的内存 Electron session，显式配置代理或直连，不依赖 TUN 或 Windows 系统代理。该 session 不共享聊天网页 Cookie，HTTP 请求仍保留原有的重定向限制和显式鉴权头。设备 WebSocket 使用同一软件代理地址建立 HTTP CONNECT 隧道。

## 用户验收

按仓库约定，智能体只构建、不启动 Electron、不运行测试、不请求真实后端。用户可运行以下离线回归，测试全部使用模拟 session、HTTP 和 WebSocket：

```powershell
node --test tests/software-proxy.test.mjs tests/release-notes.test.mjs tests/backend-settings.test.mjs
```

用户通过 `npm run dev` 验收：

1. 关闭 Clash TUN，保持本地代理监听，在网络代理中检查默认软件代理地址。
2. 保存后打开版本更新说明，检查列表、正文和已读登记；在后端服务中检查登录与设备查询，并检查设备连接。
3. 修改软件代理并保存，重新打开设置及重启应用，检查保存值仍在；清空并保存后检查直连值同样保留。
4. 输入无效地址后保存，检查错误提示、焦点和输入保留，其他设置不应部分保存。
5. 检查网页、SSH 和更新下载代理仍独立，已连接设备不会因修改软件代理而被主动断开。

交付状态为“构建通过，等待测试”；构建不代表实际代理连接已经验收。
