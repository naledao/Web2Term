# 专注对话按需技能

ChatGPT / DeepSeek 专注输入框在开头或新一行输入 `//`，显示“压缩会话、定时任务、邮件通知、电脑操作”。可继续输入中文名称或英文关键词过滤，使用上下键和 Enter 选择、Esc 收起；输入法组合输入期间不触发选择。普通 URL 和行中 `//` 不打开菜单。

压缩会话保持独立的后台工作流。其余三项加入本次输入的可移除技能标签，可组合选择。选择不会发送消息、创建计划、发送邮件、执行桌面动作或修改工具开关；必须填写任务内容或添加附件，然后由用户发送。缺少周期、邮件内容、操作目标等关键信息时，模型先澄清。

自动系统提示词和工具目录只保留文件读取、后台任务及它们的可用状态。“工具提示词”窗口也只显示这两项的摘要、提示词和开关。定时任务、邮件通知、电脑操作的摘要、完整说明、关闭提示、邮箱配置提示、电脑状态和步骤令牌均不常驻发送。已有会话中的历史提示词不会被删除或撤回，右侧计划管理页等既有入口继续保留。

三项按需能力的设置分别位于 `//` 菜单对应条目右侧的齿轮，已选择的标签上也提供设置按钮。每次只打开当前技能的启用开关和说明，电脑操作的回传间隔也在自己的技能设置中管理。旧“工具提示词”入口不再展示三项能力，也不再承担它们的启用入口；持久化设置与原有权限检查继续复用。

基础系统提示词明确区分当前工具目录、网页平台真实提供的检索能力和用户本次选择的技能。未选择的技能不主动加载，历史工具说明、旧权限和旧令牌不代表当前可用；读取技能说明后继续当前目标，不把说明当成新任务，不为使用技能而执行多余动作。缺少能力时说明限制并引导用户选择相应技能，不擅自更改开关。命令、questions 和“任务完成”的原有协议保持一致。

用户发送选中技能的任务时，主进程验证技能名称、工具设置与当前环境。通过同一条用户消息携带简短激活说明，要求模型先调用既有的 `read_tool_prompt` 读取选中的工具说明，再处理用户正文。完整说明通过既有任务绑定通道回传，保持会话、提交、页面 epoch 和取消检查。电脑操作的定义及当前步骤令牌在实际读取时生成，不提前冻结进草稿，也不随每次系统提示词更新发送。工具执行及结果回传协议继续使用原实现。

选择电脑操作仍要求当前对话已开启该工具，并满足本机、平台、系统和架构限制；不自动开启设置。桌面助手未就绪时只阻止携带电脑技能的专注任务发送，普通专注聊天继续使用原消息通道。主进程不再为普通原始网页输入设置全局桌面助手发送锁；桌面执行的实际权限及可用性检查仍由原执行器负责。

标签与文字草稿按工作区、平台和连续对话视图保存。发送成功后清除本次标签；发送失败或结果不确定时保留，避免自动重发。标签可逐项移除，已关闭、未配置或不适用的技能显示原因，并提供对应技能的设置入口。电脑技能与邮箱配置变化不会因未改变自动目录而强制重新注入相同的系统提示词。

激活说明沿用已有用户正文边界，专注消息气泡和任务目标只显示用户正文。额外说明按实际确认结果记入上下文统计，未确认时标记不确定；未选择技能的普通发送不增加这部分文本。用户正文仍限 20,000 字符；内部专注发送为激活说明预留最多 2,000 字符，非专注发送的限制不变。附件仍沿用原上传及归属检查。

参考 [OpenAI Skills 说明](https://developers.openai.com/plugins/concepts/skills)中工具负责动作、技能组织流程的边界，以及 [Anthropic Agent Skills 说明](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)中按需加载详细说明的方式。这里是软件自己的技能菜单，复用现有网页通道，不依赖平台的私有技能 API。

真实验收由用户使用 `npm run dev`：

1. 在 ChatGPT / DeepSeek 输入 `//`，检查四项技能、中文过滤、上下键、鼠标选择、Esc 和中文输入法；普通 URL 不打开技能菜单。
2. 分别选择三项按需技能，检查选择和移除不发送消息，普通任务不会自动携带这三项说明；可通过“查看系统提示词”核对自动目录。
   打开“工具提示词”窗口，确认只显示文件读取、后台任务；在 `//` 菜单点击每项技能的齿轮，分别查看或修改该技能的设置，关闭后返回原技能条目。
3. 选择定时任务并描述具体周期与任务，发送后检查先读取说明，再创建或澄清参数；取消选择后没有计划被创建。管理既有计划仍使用真实编号和版本。
4. 配置邮箱后选择邮件通知，检查内容与收件范围、说明读取、真实发送回执；未配置时给出原因，不自动改配置或重复发送。
5. 在支持的本机环境开启电脑操作后选择该技能，检查最新说明和步骤令牌读取、实际回传与后续步骤；远程和关闭状态不可选择。不选择电脑技能时，桌面助手状态不阻止普通专注消息。
6. 发送失败、切换视图、切换会话、首条消息生成新地址、重启和压缩承接时检查草稿与标签归属；带附件任务和接近 20,000 字符的输入也能进入原发送路径。
