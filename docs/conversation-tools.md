# 按对话管理工具

点击控制面板中的“查看工具提示词”打开工具弹框。每块区域包含中文工具名称、当前启用状态、开关和可展开的提示词，展开后可复制该工具的提示词。关闭工具时仍可查看启用后的提示词预览。

| 工具 | 新对话默认状态 |
| --- | --- |
| 文件读取 | 开启 |
| 后台任务 | 开启 |
| 电脑操作（computer use） | 关闭 |

computer use 已从应用设置移入“电脑操作”区域，展开“电脑操作设置”可配置结果回传间隔并查看当前环境能力。开关立即自动保存；回传间隔在离开输入框或按 Enter 时保存。

## 对话归属与持久化

主进程通过现有 SQLite settings 表持久化工具配置。已有对话按平台和对话 ID 取值，重新打开同一对话恢复其配置；其他对话使用各自的配置。旧全局 computer use 开关不再决定当前对话的能力。

尚未获得对话 ID 时，选择按工作区会话和平台保存在新对话草稿中。确认首条用户消息后，新对话取得 ID 时原子关联草稿并清空草稿；进入其他历史对话不会继承未发送草稿，也不会覆盖历史对话的已有选择。下一次新建对话重新使用默认状态。

读取、修改和变更通知都带会话、平台和对话归属。主进程拒绝来自旧会话或旧对话的修改，避免异步保存写入切换后的对话。设置写入失败时保留原开关并显示错误。

## 提示词与执行

工具提示词按当前对话的开关组合。关闭文件读取后不再注入 read_files 定义，关闭后台任务后不再注入 background_task 定义，并附带当前对话的关闭状态说明。computer use 的能力、识别、执行和回传间隔全部从对话配置读取。

修改后，下次用户发送使用更新后的工具提示词，不改变当前任务代次或清除尚未回答的问题。系统提示词仍通过原入口单独查看。

开关同时接入主进程接纳和执行检查，覆盖任务关联请求、普通页面请求、已排队请求的手动运行，以及文件准备和上传前的复核。关闭后台工具也阻止旧后台登记标记创建新的后台记录。已存在的后台进程沿用自身生命周期。

## 用户测试

新增 `tests/conversation-tools.test.mjs`，使用真实内存 SQLite 和实际持久化、提示词及运行时方法，覆盖默认值、跨对话和平台隔离、重开恢复、首次发送关联、历史对话隔离、无效设置、事务回滚、过期保存及提示词刷新。`tests/task-tool-collaboration.test.mjs` 补充关闭工具后的接纳、手动运行和准备中取消用例。

由用户运行：

```powershell
node --test tests/conversation-tools.test.mjs tests/task-tool-collaboration.test.mjs tests/computer-use-capabilities.test.mjs tests/computer-diagnostics.test.mjs
```

真实界面通过 `npm run dev` 由用户启动、操作并验收。交付状态为构建通过、等待测试。
