# 客户端版本更新说明

标题栏右侧的“版本更新说明”按钮打开版本列表与正文弹窗。按钮上的数字是这台客户端实例对全部已发布说明的未读总数，超过 99 显示 `99+`。弹窗支持刷新、分页加载、版本选择、当前客户端版本标识，以及明暗主题；请求失败、没有发布记录和正文加载失败分别显示提示和重试入口。

## 数据与阅读状态

- 主进程从客户端“设置 → 后端服务”的生效地址请求公开 API。默认开启“强制覆盖后端地址”，使用 `https://web2term.kangnasi.xyz` 并覆盖以前保存的地址；关闭并保存后可使用自定义地址及反向代理路径前缀。详见 [地址设置规则](backend-address-settings.md)。
- 沿用本地持久保存的 `localMachineId`，主进程将 UUID 统一为小写；渲染进程不能指定机器 ID 或任意请求地址。
- 无需登录，不读取或发送用户 JWT、MCP 管理令牌或会话 Cookie。三个 IPC 方法只对应用主窗口的主 frame 开放。
- 列表和详情 GET 不登记已读。正文在隔离 iframe 中完成加载后，才 POST 对应版本的已读接口；仅打开列表、请求失败或已经切换离开的正文不会发起登记。
- 登记失败保留未读状态，显示“重试保存已读”，不会自动反复提交。成功后更新列表状态并重新读取服务端未读总数。
- 启动、窗口重新获得焦点、网络恢复和每五分钟刷新角标；关闭弹窗也保留角标刷新。打开弹窗重新读取第一页并选择最新一条，更多版本通过“加载更多”获取。
- 后端地址变化会取消在途请求、清空旧列表、正文与未读数，再从新后端读取。详情与已读请求携带主进程返回的来源标记，防止把旧后端的版本 ID 提交到新后端。列表与登记并发时保留本次会话已经确认的已读结果。

正文使用格式标签白名单，在 inert template 中处理，再放入不授予脚本、同源、弹窗或表单权限的 sandbox iframe。移除事件、外部资源、样式和导航属性；保留常用标题、段落、列表、代码、表格及内嵌位图。链接文字可读，不提供正文内跳转。额外 CSP 禁止脚本、表单和远程资源。HTML 不进入应用主文档，iframe 也无法访问 preload API。

弹窗打开时沿用现有全局弹层规则，立即隐藏原生聊天视图，关闭后由当前会话的既有可见性逻辑恢复；不会关闭会话或中断任务。

## 实现位置

- `src/shared/release-notes.ts`：IPC 数据契约。
- `src/main/release-notes.ts`：公开 API 请求、超时、响应上限、结构校验和后端切换保护。
- `src/main/index.ts`、`src/preload/index.ts`：主窗口权限检查、桥接和后端变更通知。
- `src/renderer/src/components/ReleaseNotes.tsx`：按钮、未读角标、版本列表、正文与已读保存。
- `src/renderer/src/components/release-notes-document.ts`：隔离正文文档。

后端接口见 [更新说明 API](../backend/docs/release-notes.md)。客户端不会访问管理 API，发布与维护继续使用 MCP。

## 用户验收

按仓库约定，智能体不启动 Electron、不请求真实后端、不运行测试。由用户执行离线回归：

```powershell
node --test tests/release-notes.test.mjs
```

测试使用模拟 fetch 和实际渲染回调，覆盖无凭据请求、分页、响应边界、网络/重定向失败、后端切换、显示正文后的已读回调、保存失败重试、IPC 主 frame 权限，以及列表与已读结果并发。测试本身不启动 Electron 或访问真实服务。

由用户通过 `npm run dev` 验收：

1. 无需登录即可点击标题栏按钮；检查空列表、已发布列表和当前版本标识。
2. 有未读记录时，检查角标；选择正文并等待显示后，角标及未读点更新，重启后仍保留已读。
3. 模拟断网，检查列表/正文重试；登记已读失败时正文保留，状态保持未读，可手动重试保存。
4. 在原始聊天视图中打开弹窗，确认正文不被原生网页盖住；关闭后当前会话恢复。
5. 检查明暗主题、窄窗口、键盘选择和关闭，以及超过一页时的“加载更多”。
6. 切换后端后，检查旧记录与角标清空，旧请求不会回填。含脚本、表单、远程图片与链接的说明只显示允许的内容，不执行或跳转。

交付状态为“构建通过，等待测试”；构建不代表真实后端、阅读状态和界面交互已经验收。
